# ORDERTRACE · VISTA-01 시각 순서 과제

**연구 질문:** 저속 촬영 프레임을 **그대로 반복**한 영상과 컴퓨터가 **중간 프레임을 생성(보간)**한 영상에서,
사람이 두 사건(빨간 물체·파란 물체가 흰 선을 통과)의 실제 순서를 다르게 판단하는가?

## 세 가지 실행 방법

| 방법 | 참가자 | 기록 |
| --- | --- | --- |
| **웹** https://phaduche.github.io/ordertrace-study/ | 링크 열고 코드 입력 | 끝 화면에서 `vista01_코드.csv` 내려받아 연구자에게 전달 → [researcher.html](https://phaduche.github.io/ordertrace-study/researcher.html)에서 합치기 |
| **연구자 노트북 서버** `python3 server.py --lan` | 같은 와이파이에서 `http://<노트북 IP>:8000/` | 자동 저장 (`data/`) → http://localhost:8000/admin.html 에서 요약·CSV |
| **로컬 파일** 저장소를 받아 `index.html` 열기 | 더블클릭 | 끝 화면에서 CSV 내려받아 전달 |

## 자극 설계 (`make_stimuli.py`)

| 항목 | 값 |
| --- | --- |
| 원본 | 320×240, 120fps, 1.0초 합성 영상. 빨간 원(x=100)·파란 원(x=220)이 아래로 움직여 y=150 흰 선을 통과 |
| 정답 | 해석적 궤적에서 통과 시각을 계산. SOA>0이면 빨강이 먼저 |
| 관측 fps | 5 / 10 / 15 (위상은 클립마다 무작위) |
| 재구성 | `repeat`: 관측 프레임 반복(hold) · `interp`: Farneback 양방향 광학흐름 + 가중 혼합(고정 파라미터) |
| 출력 | 두 방식 모두 60fps, 60프레임, 같은 해상도 (스프라이트 시트 JPG) |
| SOA | ±33ms, ±83ms (본시행) · 167ms (연습) |
| 운동 | 가속(accel) / 감속(decel) — 등속이면 선형 보간이 정확해서 순서가 바뀔 여지가 없음 |
| 본시행 | 4 SOA × 3 fps × 2 방식 = 24회, 참가자마다 무작위 순서, 12회 뒤 휴식 |

`python3 make_stimuli.py` (OpenCV·numpy 필요, 약 10초)로 다시 만듭니다. 설계를 바꾸려면 파일 위쪽의 `SOAS_MS`, `FPS_LEVELS`, `METHODS`, `PROFILES`를 고칩니다.
생성된 자극은 저장소에 함께 있어 바로 실행됩니다.

## 과제 (`index.html`, `task.js`)

참가자 코드·동의 → 안내 → 연습 1회(피드백, 틀리면 재시도) → 본시행 24회 → 완료(확인 코드, CSV 저장, 연구 목적).
영상은 캔버스에서 60fps로 **1회만** 재생되고(3초 카운트다운), 응답은 라디오 4개(A/B/S/U 단축키) + 확신도 0~100.
재생 중 건너뛴 프레임 수와 재생 길이를 기록해 `anomaly`(건너뜀 >3 또는 길이 오차 >150ms)로 표시합니다. 탭이 가려지면 재생이 느려져 켜질 수 있으니 참가자는 탭을 앞에 두고 진행합니다.

## 데이터

- `ot_sessions`: 세션 id, 참가자 코드, 시작·완료 시각, 시행 순서, 확인 코드
- `ot_trials`: 시행별 조건(방식·fps·SOA·운동·정답), 응답, 확신도, 반응시간, 재생 이상
- CSV의 `wrong_definite` = 실제 순서와 다른 특정 순서(red/blue)를 단정한 시행 → **단일 1차 결과**는 이 비율의 방식 간 차이

## 주의

- 합성 자극은 파일럿·기술 점검용입니다. 본실험에는 120fps 실촬영 영상으로 교체를 권장합니다(`source_frames()`만 바꾸면 됩니다). 보간도 단순 광학흐름 방식이라 5fps에서 잔상이 보이므로, RIFE 등 공개 모델로 교체를 검토하세요(`interpolate()`만 바꾸면 됩니다).
- 사람 대상 자료 수집은 IRB 승인 뒤에만 합니다.
- `index.html`, `task.js`, `stimuli/`를 고쳐 main에 머지하면 웹이 자동으로 다시 배포됩니다.
